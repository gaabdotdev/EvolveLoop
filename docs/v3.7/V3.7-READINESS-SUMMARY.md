## Largest risks before goals doc

1. **Lineage split** — implementing V3.7 on bench-obs without V3.5/V3.6, or assuming they are already unified.  
2. **Promoting single-host Ops to multi-host** without fencing/auth redesign.  
3. **Harness outside bwrap** — provider auth path remains host-trusted.  
4. **Exactly-once temptation** — ADR-V3-0006 forbids the claim; distribution amplifies at-least-once.  
5. **Dual schedulers / dual event buses** — name collisions already documented in V3 reconciliation.

## Decisions that must precede official V3.7 goals

1. Integration spine: which tip becomes the merge base (recommend V3.6 tip + cherry-pick bench-obs, or explicit integration branch).  
2. Control Plane topology: single leader vs multi-CP.  
3. Node identity & revocation model.  
4. Workspace transport vs remote mount.  
5. What remains local state vs global authority.

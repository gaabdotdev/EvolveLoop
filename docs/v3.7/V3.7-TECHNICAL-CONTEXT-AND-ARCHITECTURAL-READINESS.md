## 1. Executive Summary

EvolveLoop today is a **local-first agent orchestration system** with two stacked planes that must not be conflated:

1. **V2 Execution Kernel** — Capability IR → Policy → Scheduler → Providers (`ExecutionEngine`).  
2. **V3 Coordination / Product Plane** — Goal Contract → TaskGraph → Agent Registry → Coordinator → Engineering Loop.

On top of V3, two **later lines of work exist but are not present on the audit workspace HEAD**:

3. **V3.5 Runtime** — bubblewrap sandbox, coordinator daemon + Unix IPC + leader lock, approval broker, doctor, workspace ownership.  
4. **V3.6 Global Ops** — single-host multi-project/multi-workflow admission (`GlobalOpsService`), resource leases, ops TUI — built **on** V3.5.

Separately, HEAD (`feature/bench-obs-v1`) adds the **Measurement Plane** (telemetry, ABC benchmarks, ROI, retention).

**Critical fact for V3.7:** these three post-`v3-complete` lines **diverge**. Designing a distributed “Adaptive Agent Fabric” without first choosing an integration spine will encode false assumptions.

**V3.7 feasibility (preview):** reusable single-host control/execution/security/ops/obs pieces are strong; **distributed** node identity, remote execution protocol, work stealing, speculative execution, and multi-host fencing are largely `NOT_IMPLEMENTED` and require architectural decisions before coding.

## 22. Distributed Execution Analysis

**Local today:** task ownership via WorkLock + (V3.5) LeaderLock; execution via providers/harness; persistence FS.

**Remote needs (gaps):**

| Concern | Gap |
|---------|-----|
| Receive task | No worker RPC API |
| Validate contract | Goal/Task types exist — need wire format |
| Prepare env | Worktree/sandbox local — need transport |
| Stream events | MP/EventBus local — need export |
| Cancel | PID-local — need remote cancel + fence |
| Artifacts | Need CAS or git bundle protocol |
| Reconcile | Ops recovery socket-local |

**Difference local vs remote:** trust boundary moves from “same UID/host” to “authenticated node”; ownership must survive network partitions via leases/generations.

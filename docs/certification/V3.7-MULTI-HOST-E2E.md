# V3.7 Multi-Host E2E — Gate G17

**Status:** `BLOCKED` (second independent Linux host offline)  
**Automation:** `scripts/v37/multi-host-e2e.sh`  
**Do not** substitute containers or dual local processes for this gate.

## Requirement

Two Worker Nodes on **independent** Linux hosts with **distinct** `/etc/machine-id` (or equivalent). Same-host containers do **not** count.

## Mandatory asserts (live battery)

When `EVOLVELOOP_MULTIHOST_LIVE=1` and ≥2 reachable hosts:

1. SSH BatchMode reachability to each host.
2. Distinct machine identities (`uniq_count >= 2`) else **FAIL**.
3. Control Plane starts and publishes `tls.json` (mTLS materials).
4. Per-host: enroll → approve → ship worker credentials + CA.
5. Remote `fabric worker-serve` connects under mTLS.
6. `fabric dispatch --deliver true` must contain `"result_accepted"` (ack alone = **FAIL**).
7. Revoke first worker; post-revoke dispatch must **not** select that worker.
8. Post-revoke dispatch on the remaining host must also contain `"result_accepted"` (ack alone = FAIL).
9. Evidence files under `$EVIDENCE_DIR` (enroll/approve/dispatch/revoke/post-revoke).

Dry-run without `EVOLVELOOP_MULTIHOST_LIVE=1` exits **BLOCKED** with `automation=ready` after identity checks — never PASS.

## Reproducible commands (no ambiguous manual steps)

```bash
# 0) Build Control Plane machine
cd orchestrator && npm ci && npm run build

# 1) Preflight only (identity + SSH) — exits BLOCKED if second host down
WORKER_HOSTS=gaab,gaab-1 \
  bash scripts/v37/multi-host-e2e.sh
# Expected while gaab-1 offline: {"state":"BLOCKED","reason":"host_unreachable_or_no_ssh",...}

# 2) Optional Tailscale auto-detect (≥2 online Linux peers)
AUTO_DETECT_TAILSCALE=1 bash scripts/v37/multi-host-e2e.sh

# 3) Full live battery (only when both hosts SSH-ready)
WORKER_HOSTS=gaab,gaab-1 \
EVOLVELOOP_MULTIHOST_LIVE=1 \
CP_BIND_HOST=<tailscale-or-lan-ip-of-cp> \
EVIDENCE_DIR=/tmp/g17-evidence \
  bash scripts/v37/multi-host-e2e.sh
# PASS only if JSON state=PASS and evidence_dir populated
```

## External action to unblock

1. Bring online a second authorized Linux host (historically `gaab-1` / `100.121.169.97`) with SSH BatchMode from the Control Plane host and a distinct `machine-id`.
2. Re-run step 3 above; archive `$EVIDENCE_DIR` into `docs/certification/final/evidence/g17/`.
3. Only then may G17 move from BLOCKED → PASS in the executive verdict.

# ADR-V36-0006 — Adaptive team composition

**Status:** Accepted  
**Date:** 2026-11-12

## Decision

TeamComposer produces auditable AgentTeamPlan (roles, justification, alternatives, resources). Optimizes for benefit vs coordination cost — not agent count. Respects workflow/project/resource caps. Does not raise Core subagent limits. Measurement provenance unavailable → no numeric ROI claim.
